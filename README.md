## Update Policy

1. Google Colabで自主練習し、GitHubの `usakooon/gci-learning-portfolio` の `gci-2026-winter/notebooks/` に `NN_topic.ipynb`（回数は2桁、トピックは英小文字とアンダースコア）の名前でNotebookを1つずつ保存します。
2. [Winterの記録方法](gci-2026-winter/README.md)に従い、AI作成の問題と本人の解答・解説を明確に分けます。空欄をAIで補完して本人の成果として扱いません。
3. Notebookを追加・更新したら、このREADMEの進捗表の該当行にトピック、実在するNotebookへの相対リンク、確認した進捗を記載します。進捗表はこのページで一元管理します。
4. 既存の学習記録・コード・実行結果を保持し、修正理由や追記日を必要に応じて残します。コミット履歴を書き換えません。
5. 公開前にセル・出力・メタデータ・添付ファイルを確認します。配布Notebook、宿題の問題文・正解コード、受講者限定資料・データセット、APIキー・認証情報・非公開データは掲載しません。

練習問題は一般的な学習項目から独自に作成したものだけを使用し、データには架空の値や公開・再配布が認められたものを用います。修了証は氏名・受講者番号・QRコード・ファイルのメタデータなどを確認し、公開しない情報を除いた版を掲載します。

このREADMEと各講座のREADMEの構成・文章作成にはAIを使用しています。受講状況・学習内容は本人から提供された情報に基づきます。本人の解答・解説や実行結果はまだ追加していません。
